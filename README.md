# Kırık Mühür — Dikey Pixel RPG

Özgün 2D fantastik mobil RPG prototipi. Kung Fu Saga'nın dikey ekran, görev takibi, otomatik rota ve savaş mekaniği genel referans alınmıştır; orijinal oyun görselleri ve kaynak kodları kullanılmaz.

## Aşama
3. aşama sürüm 3.6: HUD, görev döngüsü, menüler ve savaş kontrolleri.

## Çalıştırma
`index.html` dosyasını masaüstü veya Android tarayıcıda aç. Harici servis gerektirmez.

## Kontrol
HTML/JS ve 360×800, 393×852, 412×915 ile 800×360 ekranlarının Chromium testleri; görev başlatma, yaratık öldürme, ödül, ikinci beceri ve basılı saldırı akışları.

**Durum:** Oynanabilir test prototipi; gerçek cihaz ve sanat kalitesi testleri henüz tamamlanmadı.
